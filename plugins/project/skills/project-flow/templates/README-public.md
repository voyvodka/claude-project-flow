---

**Before publishing, decide what goes with it.**

`docs/product/` is process memory: decisions, rejected alternatives, assumptions, working notes —
often in the team's own language rather than English. Publishing it is a real choice with a case
on both sides. It is unusually honest documentation and can be worth more than the README to
someone evaluating the project; it also exposes internal reasoning, dead ends, and commercial
thinking that may not be intended for an audience.

Decide deliberately, and check the same for commit history, `CLAUDE.md`, and anything under
`docs/research/` that quotes sources or prices.
